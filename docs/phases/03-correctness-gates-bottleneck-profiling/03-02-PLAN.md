# Plan 03-02: Model-Level Quality Gate & Golden Baseline (QUAL-02)

**Phase:** 3-Correctness Gates & Bottleneck Profiling
**Goal:** Implement model-level quality verification: WikiText-2 perplexity within $\pm 1\%$ of reference (7.1583) and golden prompt logit/token canary verification.
**Requirement:** QUAL-02

---

## Deliverables
1. `benchmarks/data/wiki.test.raw` — Downloaded and verified WikiText-2 test dataset (~250 KB).
2. `benchmarks/bin/run_model_gate.py` — Quality gate runner evaluating perplexity and prompt canaries.
3. `benchmarks/golden/stock_baseline_golden.json` — Recorded stock baseline golden logits and tokens.
4. `benchmarks/tests/test_model_gate.py` — Unit test verifying tolerance bounds and fail-fast behavior.

---

## Implementation Details

### Dataset Ingestion
- Script fetches `wikitext-2-raw-v1.zip` from Hugging Face GGML CI repository.
- Extracts `wiki.test.raw` to `benchmarks/data/wiki.test.raw` and verifies SHA256 checksum.

### Perplexity Evaluation
- Executes:
  ```bash
  llama-perplexity -m /root/models/Qwen3.8-27B-Uncensored-IQ4_XS.gguf \
    -f benchmarks/data/wiki.test.raw \
    -c 2048 -ngl 99 --no-mmap --temp 0
  ```
- Evaluates calculated PPL against stock baseline reference ($7.1583 \pm 0.07$, $\pm 1\%$).

### Golden Prompt & Logit Canary
- Evaluates the 6 deterministic prompt corpus files (`benchmarks/prompts/`).
- Captures first 32 tokens and completion boundary logits into `stock_baseline_golden.json`.
- Compares future runs against golden store (asserting Exact Match on early tokens and logit cosine similarity $> 0.999$).
