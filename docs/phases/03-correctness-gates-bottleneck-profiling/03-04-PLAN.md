## Implementation Details

### Workload Suite Execution
- **S1 (Interactive):** Prompt 128 tokens, Gen 128 tokens.
- **S2 (Decode / Creative):** Prompt 128 tokens, Gen 1024 tokens.
- **S3 (Prefill / Document QA):** Prompt 4096 tokens, Gen 128 tokens.
- **S4 (Agentic Multi-Turn):** Prompt 4096 tokens, Gen 1024 tokens.

### Bound Classification Methodology
- **Compute / Register Bound:** Ops where latency scales with ALU FLOPs and high register pressure (e.g. `GATED_DELTA_NET` with VGPR pressure).
- **Memory Bandwidth Bound:** Ops limited by VRAM streaming bandwidth (e.g. `MUL_MAT` IQ4_XS weight dequantization and streaming during decode).
- **Launch Latency Bound:** Ops where CPU dispatch latency dominates execution time.

### Designation of Target #1
- Highest cumulative GPU wall-time bottleneck across the target shapes is designated as **Optimization Target #1** for Phase 4 (Scaffolding) and Phase 5 (Custom Kernel Implementation).
