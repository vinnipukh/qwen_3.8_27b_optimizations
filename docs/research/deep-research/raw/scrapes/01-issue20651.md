### Problem description & steps to reproduce

When running

```
llama-server -hf unsloth/Qwen3.5-27B-GGUF:UD-Q4_K_XL \
-ngl 999 \
--temp 0.6 \
--top-p 0.95 \
--top-k 20 \
--min-p 0.00 \
-dev VULKAN0,VULKAN1 \
-c 16000

(both rtx 4080 super and rx 7900xtx)

when I tell the model "HI!"
