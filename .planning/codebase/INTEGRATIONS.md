# External Integrations & Hardware Targets

**Analysis Date:** 2026-08-25 (Updated Phase 6 / v1.0.0-gfx1100)

## 1. AMD RDNA3 Architecture (gfx1100)

The primary execution target is the AMD Radeon RX 7900 XT (`gfx1100` / Navi 31):
- **Wave32 Execution:** RDNA3 uses native 32-thread wavefronts (`WARP_SIZE=32`). All custom kernels (`impl_gemv_gfx1100.hip`, `impl_gemm_wmma.hip`) are compiled exclusively for Wave32, eliminating Wave64 branch divergence and register splitting.
- **Vector Loads:** 128-bit aligned vector memory loads (`uint64_t[2]` / `Aligned16`) are aligned to 8-byte sub-block boundaries in `block_iq4_xs`, halving global memory transaction count.
- **Hardware WMMA Cores:** Large-batch prefill ($M \ge 512, N \ge 1024$) uses hardware matrix cores through `__builtin_amdgcn_wmma_f32_16x16x16_f16_w32`. Each instruction performs a $16 \times 16 \times 16$ FP16 multiply-accumulate yielding FP32 accumulators across 32 threads in 32 clock cycles (512 FLOPs).
- **LDS Bank-Conflict Avoidance:** Double-buffered shared memory `B_lds[2][32][33]` pads rows by 1 element (stride 33 halfs = 17 mod 32), eliminating 32-way shared memory bank conflicts on column reads.

## 2. ROCm on WSL2 (ROCDXG)

The runtime environment operates across the Windows / WSL2 Linux boundary:
- **Compute Adapter Passthrough:** `librocdxg` (v1.2.2) connects the guest ROCm 7.2.1 runtime to the Windows D3D12/DXG driver stack via `/dev/dxg`.
- **Initialization Requirement:** `HSA_ENABLE_DXG_DETECTION=1` must be set before any ROCm process initialization.
- **Memory Management & Anchoring:** WSL2 DXG incurs a ~1.5–3.0 GiB reporting deficit compared to bare-metal Linux. The benchmark harness pins an empirical free-VRAM anchor (18.25 GiB), executing a strict preflight check (`preflight.py`) to prevent overcommit thrashing.

## 3. Upstream llama.cpp Integration (Anti-Fork Quilt Overlay)

Integration maintains full backward compatibility without maintaining a permanent fork:
- **Base Commit:** Pinned upstream commit `bb4caa7540188872173c44d161602d9271386413` (llama.cpp v0.2.0).
- **Quilt Patch:** `patches/0001-gfx1100-mul-mat-custom.patch` generated by `git diff` and validated via `git apply --check`.
- **Toggle Flag:** CMake option `GGML_CUDA_ENABLE_CUSTOM_GFX1100` (default `OFF`).
- **Dispatch Hooks:**
  - `ggml/src/ggml-cuda/mmvq.cu`: Intercepts `GGML_TYPE_IQ4_XS` when $M=1$ for canonical projection shapes.
  - `ggml/src/ggml-cuda/mmq.cu`: Intercepts `GGML_TYPE_IQ4_XS` when $M \ge 16$ for canonical projection shapes.

## 4. Hardware Telemetry & Monitoring (HWiNFO64)

- **Shared Memory Bridge:** `benchmarks/host/hwinfo_daemon.py` polls Windows shared memory (`Global\HWiNFO_SENS_SM2`) at 1 Hz, streaming GPU temperature, core clock, memory clock, and board power.
- **Thermal Safety Watchdog:** `benchmarks/host/thermal_watchdog.py` monitors GPU edge and hotspot temperatures, executing an emergency process termination via `wsl.exe kill` if temperature reaches 95°C.
