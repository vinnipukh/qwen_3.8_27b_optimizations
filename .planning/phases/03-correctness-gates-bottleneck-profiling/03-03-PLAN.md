## Deliverables
1. `benchmarks/bin/profile_workload.py` — Script running model inference with graph-level evaluation timing hooks.
2. `benchmarks/lib/parse_profile.py` — Parser converting raw node execution traces into aggregated op percentages.
3. `benchmarks/profiling/dispatch_overhead_report.md` — Report comparing `GGML_HIP_GRAPHS=ON` vs `OFF` dispatch latency.

---

## Implementation Details

### Profiler Bridge (`benchmarks/bin/profile_workload.py`)
- Leverages `llama-eval-callback` / `ggml_backend_sched_set_eval_callback` to measure microsecond duration of each tensor operation on ROCm0.
- Collects:
  - Op Name (`GATED_DELTA_NET`, `SOLVE_TRI`, `MUL_MAT`, `FLASH_ATTN_EXT`, `RMS_NORM`, etc.)
  - Tensor shapes ($M, N, K$, batch size, sequence length)
  - GPU Execution Latency ($\mu s$)
  - Memory Footprint (bytes)
- Separates timings into **Prefill Phase** ($M \gg 1$) and **Decode Phase** ($M = 1$).

### Dispatch Overhead Audit
- Measures wall-clock time vs kernel compute time with `GGML_HIP_GRAPHS=ON` vs `GGML_HIP_GRAPHS=OFF`.
- Calculates CPU dispatch latency per kernel launch to evaluate if RDNA3 is launch-latency-bound.
