# Plan 03-01: Op-Level Correctness Gate (QUAL-01)

**Phase:** 3-Correctness Gates & Bottleneck Profiling
**Goal:** Implement automated op-level verification wrapper executing `test-backend-ops test -b ROCm0` across all 128 ops with zero-tolerance failure enforcement.
**Requirement:** QUAL-01

---

## Deliverables
1. `benchmarks/bin/run_op_gate.py` — Python CLI running `test-backend-ops` under WSL2 ROCm0.
2. `benchmarks/results/phase3/op_gate.json` — Structured test results report (JSON).
3. `benchmarks/tests/test_op_gate.py` — Unit test verifying that a failing op produces exit code 1 and blocks acceptance.

---

## Implementation Details

### CLI Runner (`benchmarks/bin/run_op_gate.py`)
- Executes:
  ```bash
  export HSA_ENABLE_DXG_DETECTION=1
  export LD_LIBRARY_PATH=/root/llama.cpp/build-ci/bin:$LD_LIBRARY_PATH
  /root/llama.cpp/build-ci/bin/test-backend-ops test -b ROCm0 --output csv
  ```
- Parses per-op pass/fail status.
- Strict assertion on core Qwen hybrid architecture operations:
  - `GATED_DELTA_NET`
  - `SOLVE_TRI`
  - `SSM_CONV`
  - `SSM_SCAN`
  - `FLASH_ATTN_EXT`
  - `MUL_MAT`
- If all ops pass: exits with code `0` and writes structured `op_gate.json`.
- If any op fails: exits with code `1` and emits failure details.

---

## Verification Criteria
- [ ] Runner executes all 128 ops cleanly on ROCm0 (RX 7900 XT).
- [ ] Core hybrid operations explicitly asserted and marked `PASS`.
- [ ] Synthetic failure test in `test_op_gate.py` proves red runs produce exit code 1.
