## Implementation Details

### CMake (top-level)
```cmake
cmake_minimum_required(VERSION 3.21 FATAL_ERROR)
project(kernels_playground LANGUAGES HIP CXX)
set(CMAKE_HIP_ARCHITECTURES "gfx1100" CACHE STRING "gfx1100 only - no amdgpu-arch auto-detect")
set(CMAKE_HIP_STANDARD 17)
set(CMAKE_CXX_STANDARD 17)
list(APPEND CMAKE_PREFIX_PATH "/opt/rocm")
find_package(hip QUIET) # optional - hip::device legacy fallback
# Ninja + ccache auto-detected; enforce -DCMAKE_HIP_ARCHITECTURES=gfx1100 on CLI as well
```

Per-op `kernels/<op>/CMakeLists.txt` standalone like `ROCm/rocm-examples/HIP-Basic/hello_world/CMakeLists.txt`:
```cmake
add_executable(template_test test_compare.cpp ref_cpu.cpp impl.hip)
set_source_files_properties(impl.hip PROPERTIES LANGUAGE HIP)
target_link_libraries(template_test PRIVATE kernels_common)
target_compile_definitions(template_test PRIVATE WARP_SIZE=32) # bench both 32/64
```

Fallback legacy: `find_package(hip REQUIRED)` + `target_link_libraries(... PRIVATE hip::device)` + `GPU_TARGETS=gfx1100` when `hipcc` is `CMAKE_CXX_COMPILER` without HIP language. Guard mixed targets: `$<$<COMPILE_LANGUAGE:HIP>:--offload-arch=gfx1100>`.

Build command (copy-paste for WSL2):
```bash
cmake -S kernels -B kernels/build -G Ninja -DCMAKE_HIP_ARCHITECTURES=gfx1100 -DCMAKE_BUILD_TYPE=Release
cmake --build kernels/build
# Probe: hipcc --offload-arch=gfx1100 --genco empty.hip && rocminfo | grep gfx1100
# Env shim: export HSA_ENABLE_DXG_DETECTION=1  # only for ROCm <7.13
```

WSL2 librocdxg constraints coded around: `.wslconfig memory=32GB` documented, `hipMemGetInfo` tolerance (~3 GB, #57), `hipMalloc`+`hipMemcpy` over UVA, gate `rocprofv3` tests to `if (non-WSL)`, avoid long-lived idle HIP contexts (2-core spin #60).

### Vendored header (`kernels/common/block_iq4_xs.h`)
```c
// Vendored from ggml/src/ggml-common.h @ bb4caa75 — Apache-2.0
#pragma once
#include <stdint.h>
#define QK_K 256
typedef struct { uint16_t d; uint16_t scales_h; uint8_t scales_l[4]; uint8_t qs[128]; } block_iq4_xs; // fp16 d as uint16_t
static_assert(sizeof(block_iq4_xs)==136, "block_iq4_xs must be 136");
static const int8_t kvalues_iq4nl[16] = {-127,-104,-83,-65,-49,-35,-22,-10,1,13,25,38,53,69,89,113};
static inline float fp16_to_fp32(uint16_t h) { /* via __half or bit hack */ }
```
Alternative: `ggml_half d` as `uint16_t` to avoid `<hip_fp16.h>` dep; document little-endian `d` + `scales_h` LE.

### Common helpers (`hip_helpers.h`)
```c
#define HIP_CHECK(ans) { hipError_t e=(ans); if(e!=hipSuccess){fprintf(stderr,"HIP %s:%d %s\n",__FILE__,__LINE__,hipGetErrorString(e)); abort();} }
#define HIP_EVENT_CHECK(ans) HIP_CHECK(ans)
```
Also `hipStream_t` helpers, `warpSize` templating:
```cpp
template<int WarpSize=WARP_SIZE>
__global__ __launch_bounds__(256,4) void stub_kernel(const block_iq4_xs* src, float* dst);
```

### Bench helper (`bench.h`)
```cpp
struct BenchStats { double median_us, p95_us, min_us, max_us, stdev_us; int count; };
BenchStats bench_hip_event(std::function<void(hipStream_t)> launch, hipStream_t s, int warmup=50, int iters=200);
// Internally: hipEventCreate(&start/stop); for warmup... launch(s); hipEventRecord(start,s); launch(s); hipEventRecord(stop,s); hipEventSynchronize(stop); hipEventElapsedTime(&ms,...)
// Never hipEventDisableTiming when hipEventElapsedTime needed; never hipEventRecord inside captured HIP graphs (ROCm unsupported)
```

### Template quartet skeleton
- `ref_cpu.cpp` — pure C++17, no HIP, calls `dequantize_row_iq4_xs` oracle (vendored logic) or simple `stub_ref`.
- `impl.hip` — `__global__` + host launcher `stub_gpu()` returning `hipError_t`.
- `test_compare.cpp` — calls both, computes `max_abs/mean_abs/cosine`, `assert GREEN` for correct, `assert RED` for broken (see 04-03).
- `bench_sweep.cpp` — loops `bench.h` over `n_blocks ∈ {1,8,64}` + `WARP_SIZE 32/64` both, writes `bench_sweep.json`.

Isolation gate script `scripts/check_no_ggml.sh`: `! rg -q "ggml|llama" kernels/` else fail CI.
