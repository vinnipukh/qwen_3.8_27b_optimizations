## Implementation Details

### Real GGUF dump (`tools/dump_gguf_fixtures.py`)
```python
from gguf import GGUFReader
from gguf.constants import GGMLQuantizationType, GGML_QUANT_SIZES
from gguf.quants import quant_shape_to_byte_shape, dequantize
import numpy as np, hashlib, json, pathlib

reader = GGUFReader("models/Qwen3.8-27B-Uncensored-IQ4_XS.gguf") # memmap, LE handling automatic
# Inspect: for t in reader.tensors: print(t.name, t.tensor_type, t.shape, t.n_elements, t.n_bytes, t.data_offset)
assert GGML_QUANT_SIZES[GGMLQuantizationType.IQ4_XS] == (256, 136)  # 4.25 bpw

# Select N tensors (owner-approved shapes for Phase 5)
wanted = ["blk.0.attn_q.weight", "blk.0.ffn_down.weight"]  # plus any 4096×4096
for name in wanted:
    t = next(x for x in reader.tensors if x.name==name and x.tensor_type==GGMLQuantizationType.IQ4_XS)
    raw = t.data  # np.uint8 view reshaped via quant_shape_to_byte_shape; shape (*, n_blocks*136)
    # Or contiguous copy: raw_bytes = reader.data[t.data_offset : t.data_offset + t.n_bytes].tobytes()
    f32 = dequantize(raw, GGMLQuantizationType.IQ4_XS)  # shape (*, n_elements) via gguf-py grid path
    # Header + raw + dequantized
    out = pathlib.Path(f"kernels/fixtures/{name.replace('.','_')}.iq4xs.npz")
    np.savez(out, raw=raw, f32=f32, shape=np.array(t.shape), block_size=256, type_size=136)
    # Also dump first block hex for docs: raw.reshape(-1,136)[0][:8].hex()
```

`GGUFReader` details: memmap, validates `GGMF_MAGIC`, handles `byte_order='S'` swap, aligns `data_offset` to `general.alignment` (32), validates via `reader.data[t.data_offset : t.data_offset + t.n_bytes]`. CLI helper `python -m gguf.scripts.gguf_dump model.gguf --tensors` prints metadata; `examples/reader.py` pattern.

CLI spec:
```bash
python tools/dump_gguf_fixtures.py \
  --model models/Qwen3.8-27B-Uncensored-IQ4_XS.gguf \
  --tensors blk.0.attn_q.weight --tensors blk.0.ffn_down.weight \
  --num-blocks 8 --out kernels/fixtures/
# Writes kernels/fixtures/blk_0_attn_q_weight.iq4xs.npz + .bin + manifest.json
```

Manifest per-tensor:
```json

```

### Synthetic fixture path (deterministic, no GGUF needed — covers gaps)
```python
import numpy as np
from gguf.constants import GGMLQuantizationType
from gguf.quants import quantize, dequantize

rng = np.random.default_rng(0)
f32 = rng.standard_normal((2, 256), dtype=np.float32)  # last dim %256==0
q = quantize(f32, GGMLQuantizationType.IQ4_XS)  # uint8 (2,136)
f32_rt = dequantize(q, GGMLQuantizationType.IQ4_XS)
# Fallback if gguf-py quantize for IQ4_XS unimplemented in older wheels:
# Use C reference: quantize_row_iq4_xs_ref(src, dst, 256) via ctypes / ggml-quants.c
```

Edge cases to emit as separate `*.npz` fixtures:
- Zero block (`d=0` or `ls_signed=0` for all 8 sub-blocks)
- Max scale `ls=63 → ls_signed=+31`, min `ls=0 → -32`
- All nibbles `0` / `15` / alternating `0x0F0F`
- Split-half boundary: values stressing `lo@i` vs `hi@i+16` (e.g. `qs[0]=0x12` where `lo=2` high `1`)
- Sub-block isolated: only sub-block 3 non-zero, rest zero → validates `scales_h` 2-bit lane `3` + `scales_l[1]` high nibble

Each synthetic file tagged `synthetic: true, seed: 0, case: "max_scale"` in manifest.

### Layout table for README (copy from 04-CONTEXT)
| Offset | Size | Field | Encoding |
|---|---|---|---|
| 0 | 2 | `d` | fp16 LE super-block scale |
| 2 | 2 | `scales_h` | u16 LE, 2-bit high per sub-block (8×2) |
| 4 | 4 | `scales_l` | 4×u8, 4-bit low per sub-block (2 per byte) |
| 8 | 128 | `qs` | 128 nibble-bytes, 256 indices via `kvalues_iq4nl[16]` |

Dequant formula (also in header): `ls_low=(scales_l[i/2]>>4*(i%2))&0xF; ls_high=(scales_h>>2*i)&3; ls=ls_low|(ls_high<<4); scale=d*(ls-32); w=scale*kvalues_iq4nl[lo/hi]` with `lo=qs[16*s+j]&0xF` at `s*32+j`, `hi=qs[16*s+j]>>4` at `s*32+j+16`.

### Provenance & size
- `GGML_QUANT_SIZES[IQ4_XS]=(256,136)` → 4.25 bpw, not 34B confusion (that's `block_q4_K`).
- Super-block `QK_K=256`, `scales_l` packing 2 per byte low nibble even sub-block, `scales_h` 2 bits per sub-block contiguous. Verified via `ggml/src/ggml-common.h`, `ggml-sycl/dequantize.hpp`, `oxillama AVX2` decoder.
- `block_iq4_xs` has **only** `d` (no `dmin` — K-quants have `dm` pair; IQ4_XS centres 6-bit scale at 32).
