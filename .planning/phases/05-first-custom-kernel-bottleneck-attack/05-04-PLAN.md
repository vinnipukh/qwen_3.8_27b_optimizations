## Execution Protocol

### Step 1: Microbenchmark Sweep Matrix
Run standalone microbenchmark sweeps archiving results using `benchmarks/tools/run_kernel_bench.py` and `RunStore`:
```bash
python3 benchmarks/tools/run_kernel_bench.py --bin kernels/build/matmul_iq4xs/bench_matmul --op mul_mat_iq4xs
```

### Step 2: Provisional Patch & Rebuild
Apply the provisional patch over `/root/llama.cpp`:
```bash
cd /root/llama.cpp
git apply /mnt/e/Projects/qwen_3.8_27b_optimizations/patches/phase5_mul_mat_custom.patch
cmake --build build-ci -j
```

### Step 3: Run-Level Quality Gate & Model Benchmark
1. **Op Gate (`QUAL-01`):**
   ```bash
   python3 benchmarks/bin/run_op_gate.py
   ```
2. **Model Quality Gate (`QUAL-02`):**
   ```bash
   python3 benchmarks/bin/run_model_gate.py --model /root/models/Qwen3.8-27B-Uncensored-IQ4_XS.gguf
   ```
3. **End-to-End Benchmark Session:**
   ```bash
   python3 benchmarks/bin/run_session.py --tiers 4096 8192 16384 --repeats 5 --delay 10
   ```
