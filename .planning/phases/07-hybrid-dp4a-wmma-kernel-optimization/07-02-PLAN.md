# Plan 07-02: Cooperative Wave32 DP4A GEMV Kernel (Decode Optimization)

**Goal:** Outperform stock `llama.cpp` MMVQ decode ($M=1$) by fusing 8-thread cooperative super-block decomposition with hardware DP4A instructions on `gfx1100`.

**Deliverables:**
- `kernels/matmul_iq4xs/impl_gemv_dp4a_gfx1100.hip`:
  - 8 threads cooperatively process each 256-weight super-block.
  - Aligned 128-bit memory loads for `block_iq4_xs` weights and `q8_1` integer activation vectors.
  - Native `__dp4a` / `v_dot4_i32_i8` integer dot product execution.
  - Fast intra-wave shuffle / LDS reduction across the 8 cooperative lanes.
  - Target occupancy: $\le 64$ VGPRs per thread, 16 waves per SIMD.
- `test_gemv_dp4a_compare.cpp`: Validates numerical correctness vs CPU oracle and stock DP4A.
- `bench_gemv_dp4a.cpp`: Direct speedup benchmark vs real stock DP4A across all 8 canonical shapes.

**Target:** >1.2× speedup over real stock MMVQ (targeting 40–45 t/s decode in end-to-end inference).
