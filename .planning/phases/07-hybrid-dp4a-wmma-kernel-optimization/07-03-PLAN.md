# Plan 07-03: RDNA3 WMMA Hardware Matrix Core GEMM Kernel (Prefill Optimization)

**Goal:** Outperform stock `llama.cpp` MMQ prefill ($M \ge 128$) by streaming quantized inputs into hardware RDNA3 WMMA matrix cores (`v_wmma_f32_16x16x16_f16_w32` / `v_wmma_i32_16x16x16_iu4_w32`).

**Deliverables:**
- `kernels/matmul_iq4xs/impl_gemm_wmma_stream.hip`:
  - 2D tiled workgroup staging ($64 \times 32$ output tile per block).
  - Padded double-buffered LDS (`[2][32][33]`) eliminating 32-way bank conflicts.
  - On-the-fly dequantization into WMMA input fragment registers.
  - 1024 ops/CU/clock hardware tensor core execution.
- `test_gemm_wmma_compare.cpp`: Validates numerical parity vs CPU FP64 reference oracle.
- `bench_gemm_wmma.cpp`: Evaluates prefill throughput ($M=128, 512, 1024$) vs stock MMQ.

**Target:** >1.2× speedup over stock MMQ (targeting >1000 t/s prefill in end-to-end inference).
